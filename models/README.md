# Modelos

Los modelos se separan por tipo de uso dentro de MuseIQ:

- `catalog/`: obras, piezas individuales y objetos 3D para ficha, AR o visor.
- `immersive/`: salas, edificaciones o espacios pensados para recorridos
  inmersivos.

Los `.glb` finales de produccion se copian o sincronizan hacia
`museiqApp/assets/models` cuando la app los necesita.
